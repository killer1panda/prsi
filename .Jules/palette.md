## 2024-10-27 - Screen Reader Access and Loading States Feedback
**Learning:** Pairing input elements with explicit `<label>` tags significantly improves accessibility for screen readers. Furthermore, adding specific CSS rules like `:focus-visible` supports keyboard navigation without causing styling issues for mouse users. I also learned that adding `aria-live="polite"` dynamically announces new results without stealing the focus, creating a seamless UX for assistive technologies. Lastly, although JavaScript can disable buttons during loading, ensuring a corresponding visual `:disabled` CSS state avoids user confusion during async tasks.
**Action:** Always ensure any inputs have proper labels, use `aria-live` for dynamically populated results, ensure visual disabled states for interactable elements to show application progress, and leverage `:focus-visible` to support both keyboard navigators and standard cursor users.
