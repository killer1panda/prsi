## 2024-05-18 - Optimize Pandas Regex Search in Feature Engineering
**Learning:** Using `Series.str.contains(kw)` with the default arguments enables regex searching. However, when performing simple substring searches across many rows for multiple keywords, this default behaviour creates significant overhead. Using `regex=False` allows string checking via simple substring matching under the hood, significantly speeding up the process. Pre-processing strings to avoid repetitive loop computation (`.fillna('')`, `.str.lower()`) also significantly trims unnecessary Pandas/Python overhead per iteration.
**Action:** When working with string patterns in Pandas that do not explicitly require regex features, ensure that `regex=False` is passed to operations like `.str.contains` to boost performance. Always pre-compute series values outside loop iterations.
