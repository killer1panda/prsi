# PRSI Production Model Card

## Model Details

- **Model Name**: PRSI (Predictive Real-time Social Intelligence)
- **Version**: 2.0.0 (SOTA Frontier Upgrade)
- **Organization**: PRSI Security & Social Intelligence Research Group
- **Release Date**: October 2026
- **Model Type**: Trilateral Multimodal Neural Network (LLM + Vision-Language + Temporal GNN)
- **Core Architecture**:
  - **Text**: `mistralai/Mistral-7B-Instruct-v0.3` (4096-dim, 4-bit QLoRA, $r=16, \alpha=32$)
  - **Vision**: `Qwen/Qwen2-VL-7B-Instruct` (3584-dim, Native NaViT patch grid flattening)
  - **Graph**: Hawkes GATv2 + Continuous-Time Hypergraph Neural Network (HGNN)
  - **Fusion**: 32-query Querying Transformer (Q-Former) with InfoNCE contrastive alignment
  - **Causal Reasoning**: Pearlian SCM + Double Machine Learning (DML) + DPO de-escalation rewriter
  - **Uncertainty Quantification**: Conformalized Quantile Regression (CQR, $1 - \alpha = 0.90$)
- **License**: Apache 2.0
- **Repository**: `https://github.com/killer1panda/prsi`

## Intended Use

### Primary Use Cases
1. **Outrage Cascade Forecasting**: Predict viral outrage spread before irreversible social or corporate damage occurs.
2. **De-escalation Recommendations**: Generate semantically equivalent, lower-risk counterfactual phrasing using causal DPO.
3. **Meme Risk Quantification**: Parse embedded multimodal sentiment where cynical imagery conflicts with innocuous text.
4. **Platform Safety & Resilience**: Test model robustness against adversarial Unicode and homoglyph bypasses.

### Out-of-Scope Uses
- Automated punitive moderation or account termination without human review.
- Mass surveillance of private communications or protected demographic groups.
- Generating malicious, unhedged outrage campaigns or defamatory materials.

## Training Data & Provenance

### Data Sources
- **Reddit**: Cleaned discussion threads from high-velocity topical subreddits (~450K posts).
- **Twitter/X**: Public interaction graphs with engagement timelines and retweets (~250K posts).
- **Instagram**: Public meme templates with OCR text extractions (~60K images).
- **Augmented/Counterfactual**: Causal counterfactual variants generated by DML estimators (~40K pairs).

### Preprocessing & Governance
- **Anonymization**: All user identifiers hashed with salted SHA-256; PII scrubbed via Presidio NER.
- **Emoji Swing Extraction**: Normalizes emotional valence from cynical (`🤡`, `💀`) and outrage (`😡`, `🚨`) emojis.
- **Weak Labeling**: Preserves full text while balancing classes via SMOTE.
- **Data Splitting**: Strict temporal split (70% train, 15% validation, 15% test) to prevent forward lookahead leakage.
